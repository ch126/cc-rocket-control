# CC Rocket Control

用于 CC: Tweaked 与 Create Propulsion 的五引擎同步控制器。
`engine.lua` 是红石手动版；`stabilize.lua` 是红石扶正版；`flight.lua` 是红石扶正＋定高／缓降版；新增 `wired.lua` 是创造矢量引擎有线外设版。
目前没有定点、返航、自动着陆或塔架联动。旧版文件保留，便于回退。

## v0.4.0 有线外设精细推力（wired.lua）

适用于已确认接线的这台电脑：底面有线调制解调器，远程外设 `creative_vector_thruster_0` 到 `_4`，每台基础推力上限 **733 kN**。五台共同百分比调节，不做差动控制。

### 重要：1.1.5 的接口精度与先前说明更正

逐项检查了本地 `createpropulsion-1.1.5.jar` 的实际实现，而不仅是方法的浮点参数：

- `ThrusterComputerHelpers.setThrottleNormalized` 执行 `floor(clamp(value,0,1)*15+1e-6)`，然后调用整数档油门。因此 `setThrustNormalized(0.352)` **并不能**获得真正35.2%的油门。
- `VectorThrusterBlockEntity.setVectorCoordinates` 把两轴的绝对值乘15再四舍五入，因此 `setVector(0.02,-0.01)` 实际会归零，不能当作精细偏转。
- 创造矢量引擎的 `setThrustOutput` 则直接保留浮点基础推力，乘以油门及环境因子。新版用它调整基础推力，整数油门只用0（关）和15（开），绕过油门档位限制。
- 例如1.1%指令为每台 `setThrustOutput(8063)`，配合15档使基础推力为8.063 kN；这是基于本地 `thrustUnitsPerKn=1000` 的换算。界面显示的是**基础推力指令，不是测得的实际推力**。
- 偏转仍是有效的1/15档，最多±3档；没有承诺连续小数偏转。自动高度环使用连续推力计算，不再把结果四舍五入成红石档位。

参考：[项目外设接口说明](https://github.com/Propulsion-Team/create-propulsion-simulated/blob/main/wiki/ComputerCraft-Peripherals.md)。不同构建的实现可能不同，以实际安装的 JAR 为准。

### 安装与首次运行

1. 备份世界，在低空试验条件下操作；旧程序 Q 退出。关闭／拆除原来的推力红石接收输入与喷口方向无线信号，避免外设断开时回到旧红石命令。只运行一个控制程序。
2. 电脑底面连接有线调制解调器；五台引擎的有线调制解调器加入同一电缆网并启用外设共享。
3. 如果仍在 `lua>`，先输入 `exit()`。然后在普通命令行逐行执行：

```text
wget https://raw.githubusercontent.com/ch126/cc-rocket-control/main/wired.lua wired.lua
wired
```

4. 确认界面显示 `v0.4.0 WIRED | 5 x 733 kN`、`DISARMED MANUAL`、`Power 0.0%`。启动先尝试清零五台引擎并检查名称、类型、所需方法和推力上限；缺一台不允许启动。
5. 竖直静止时 U；E解锁；R/F调推力、T/G微调。以前5/15档约为33.3%，不是新版的5%。不要直接从高推力开始试验。
6. 在可自由发生小幅转动、近竖直且几乎不转动的条件下 K 校准。正反1档脉冲，先等待喷口响应再测量，约9秒，低TPS会延长。**会实际偏转并使舰体转动，夹死的箭体不能校准。** 看见 `Calibration saved`／`calibration OK` 后才按H扶正。
7. 仍须低空验证。校准时倾角超过12度或转动过快会停机，不保证成功或不下坠。

### 按键变化

| 按键 | 功能 |
| --- | --- |
| R / F | 同步推力增加／减少1个百分点，每台7.33 kN |
| T / G | 同步推力增加／减少0.1个百分点，每台0.733 kN |
| W / S、D / A | 手动两轴偏转增加／减少1档，限±3档 |
| E | 解锁／解除控制，切换保持零指令；解锁须五台已确认清零、姿态新鲜、无锁定外设故障 |
| 空格 | 请求五台停推并回中 |
| Q / Ctrl+T | 退出并尝试逐台清零 |
| U / K / H | 新的竖直基准／脉冲校准／自动扶正 |
| J | 解除控制、静止竖直时记录本次起飞高度，不清除校准 |
| V / N | 定高／有限缓降，与v0.3逻辑一致；V要求近悬停2秒、油门1%～99%、Y≥起飞基准＋2格 |
| C | 退出自动控制、喷口回中，保留当前推力 |
| P / L | 解除控制时手动保存／加载校准 |

R/F/T/G均退出高度控制并接管推力。调节键支持长按；切换键忽略重复。0.1%是手动步长，不限制自动高度环的数值分辨率，也不等于实际飞行精度。

### 存档与输出可靠性

- 自动保存到 `/rocket-wired-calibration-v2.cfg`，与红石版存档隔离。**第一次迁移必须重新U/K，不能复制旧标定结果。** 成功后重启自动验证并加载，仍为零推力。身份、质量、引擎名称顺序、控制方式、推力上限和换算系数不符会拒绝加载。
- 不沿用上次飞行高度；加载校准后在起飞点按J。改变引擎朝向、重心、结构或参数必须重新校准，即使质量和ID没有变化。
- 733 kN和1000换算系数是本实例的已确认设置，写在程序顶部。换世界或修改模组配置后须重新核对，不能盲用。
- 按键、传感器、五个引擎输出任务分别处理。每台引擎只有一个正常写入任务；不让五台逐个串行等待。它们接收相同目标，但**不保证物理更新完全同时**。
- 急停会使旧指令失效；正在等待的调用返回后立即处理零输出。重新解锁须等五台清零确认，不能因快速按E让旧非零指令再次启用。
- 正常运行时发现断线／写入错误会锁定故障并停止其余输出，需要修复并重启。输出任务超0.6秒无完成确认、已解锁时姿态超0.5秒未更新，也触发停机；原姿态环0.35秒保护仍在。
- 清零会分别尝试油门0、基础推力覆盖0、偏转0；某个调用失败不会跳过其他引擎。看到 `CLEAR FAILED` 表示**未能确认全部清零**。
- 外设断线后无法发送停机命令给那台引擎。世界暂停、服务器卡死、区块卸载、进程强制中断也不受软件保护。五台有推力时发生非同步停机会失衡；请备份世界，不把此程序当作可靠回收系统。
- 退出保留基础推力覆盖为0（写入引擎NBT），不自动调用 `clearThrustOutput()` 恢复滚轮推力。若回退红石版，必须先确保原红石信号为0，再在连接状态下将五台油门清零并调用各自的 `clearThrustOutput()`，最后断开外设接管。只换回旧Lua文件并不足以恢复红石控制。

测试使用实际Lua程序和异步任务调度模型：25/50/100ms接口延迟、1.1.5油门／偏转取整、喷口响应平滑、五台推力输出、挂起期间急停、断线／写入失败、超时保护、存档拒绝、校准／扶正／定高／缓降和手动接管。**尚未在Minecraft世界实飞验证。**

## v0.3.0 按键修复、校准存档、定高／缓降（flight.lua）

先按 Q 退出旧程序，再下载新文件：

```text
wget https://raw.githubusercontent.com/ch126/cc-rocket-control/main/flight.lua flight.lua
flight
```

### 按键响应

按键监听和传感器采样现在运行在独立协程中；传感器等待主线程返回时，不再吞掉按键事件。`R/F/W/S/D/A` 支持长按，每次重复调节至少间隔0.12秒；`E/H/K/V/N` 等切换键仍只处理首次按下。空格急停、Q／Ctrl+T退出可在传感器等待时处理。
游戏必须把键盘焦点交给 CC 界面；服务器卡死、游戏暂停或失去焦点不在这个修复的保证范围内。
实现依据：[CC parallel 的独立事件队列](https://tweaked.cc/module/parallel.html)。

### 校准保存与加载

- `K` 成功后自动保存扶正基准轴、两轴响应矩阵、校准推力、质量、舰体 ID 到 CC 电脑的 `/rocket-calibration-v1.cfg`，不是 Windows 上的文件。
- 重启自动加载，校验格式、有限数值、轴正交性、矩阵有效性、舰体 ID 及质量差不超过5%。损坏或不匹配会拒绝加载。
- 加载不会启用引擎：仍是解除控制、零推力。确认界面出现 `Loaded; verify craft unchanged` 后，才自行 E、调推力、H。
- 解除控制时 `P` 手动保存，`L` 重新加载。正常写入先使用 `.tmp`，再把上一版保留为 `.bak`；主文件缺失时可读取备份，主文件损坏时不会静默回退。保存失败显示 `SAVE FAILED`，当前内存中的有效校准仍可使用。
- 改动接线、引擎朝向／创造推力、重心或结构后必须重新 U／K，即使 ID 和质量没有变化。程序不能识别所有这种变化。只有成功的新校准才替换存档，失败不会把坏结果写进去。
- 旧 `stabilize.lua` 没有存档，升级后首次需要重新校准。

### 定高与有限缓降

1. 第一次按原 U → E → 调油门 → K → H 流程完成扶正。U 必须在实际竖直、静止的起飞位置使用，同时记录本次高度基准。
2. 如果已加载存档，不要为了设高度再次按 U（U 会清除内存里的校准）；在起飞位置解除控制、竖直静止时按 **J** 单独记录本次高度基准。加载时不会恢复上次飞行的高度。
3. 在 H 扶正下，手动调到接近悬停：推力2～13档、升降速度绝对值小于0.4格/秒持续2秒、倾角小于8度、高度至少为本次基准＋2格，再按 **V** 捕获当前高度并启用定高。屏幕显示 `HOLD ALT`。
4. **N** 将目标高度以0.3格/秒下移，最多3格，且不低于本次基准＋2格；到目标后重新定高。再次 N 暂停缓降并锁定当前高度。这是目标变化速度，不保证实际降速严格等于0.3。
5. **V** 退出高度控制；**R/F** 退出高度控制并手调油门；**H/C** 回手动。上述操作保留当前油门（R/F另加减1档）。空格、E解除控制、Q退出会清零。

高度取自姿态参考点的世界 Y，不是箭底到地面的距离，**没有地面探测，不是自动着陆**。倾斜会影响参考点高度；16级红石、引擎响应和世界物理可能造成上下振荡。
定高推力限定在捕获值±3档且处于原校准的0.5～2倍范围内；超过边界显示 `THRUST LIMIT`，不代表仍能保持高度。
定高时倾角超过15度、测得升降速度超过4格/秒，以及原有传感器／采样异常保护，均会清零停机。空中停机会坠落；请备份世界并先做低空测试。

通过 Lua 5.2 仿真：延迟接口、真正挂起接口期间的按键、长按限速、急停、跨重启存档、损坏／不匹配拒绝、磁盘写入失败、定高／缓降及手动接管。尚未在 Minecraft 中实飞验证。

## v0.2 自动扶正（实验版）

### v0.2.1 采样延迟修复

修复 `Control loop delayed` 被串行读取开销误触发的问题。CC: Sable 的接口需要在游戏主线程执行；旧版每轮读取5个接口，再等待0.1秒，实际间隔可能超过0.35秒。
现在每轮只读姿态，并至多附带1个低频状态查询。状态检查按0.25秒以上间隔轮换，身份、质量、速度等各约1～2秒更新一次，相关变化的检测也会相应延后。姿态最后读取并立即计时，不再使用被后续查询消耗掉的旧时间戳。
界面增加 `Sample dt`，超时消息包含实际间隔。保留0.35秒保护并容忍浮点边界误差；发生真正超时仍会清零，不能将此版视作低TPS下的可靠飞控。

更新前按 Q 退出旧程序；下载到新文件，保留旧版：

```text
wget https://raw.githubusercontent.com/ch126/cc-rocket-control/main/stabilize.lua stabilize-fix.lua
stabilize-fix
```

确认界面显示 `v0.2.1`，再重新 U / E / K / H 标定和启用。
已补充每个API分别等待50/60/100毫秒的回归测试，以及600毫秒异常延迟停机测试；尚未在你的世界重新实飞。

保持原五路接线，不替换原来的 `engine.lua`。先退出其他控制程序，再安装：

```text
wget https://raw.githubusercontent.com/ch126/cc-rocket-control/main/stabilize.lua stabilize.lua
stabilize
```

CC 电脑必须组装在箭体上；需要已有的 CC: Sable 1.3.4。
界面使用英文，避免 CC 默认字体的中文显示问题。每次启动都是零推力、不自动启用控制。

### 首次运行顺序

1. 让箭体实际竖直、静止，等待界面出现质量和速度。按 `U` 记录此时箭体朝上的轴。
   程序不知道你的箭头在哪，不能把倾斜的箭体当作竖直标定。
2. 按 `E` 启用，再用 `R/F` 手动调整推力。先完成低推力、低高度试验，不直接在高空运行。
3. 在箭体接近竖直、几乎没有转动、能自由发生小幅转动时按 `K`。
   程序保持当前油门，依次对 front/back、right/left 发出正反2档偏转，约3.6秒（低TPS会延长）。
   **该步骤会实际改变喷口、使箭体转动**，不是只读检测。夹臂或地面硬锁住箭体会导致标定失败；应使用允许两轴转动的试验架，或可控的低空试验条件。
4. 看到 `calibration OK` 后，按 `H` 开启 `HOLD`。它只尝试扶正，仍要用 `R/F` 控制升降。
5. `H` 再次按下退出扶正；`C` 取消标定/扶正并回中，均保持油门。`空格` 停机解除控制；`Q` 或 Ctrl+T 清零退出。

标定时若倾斜超过12度或转动过快，会停止全部输出；降低创造引擎基础推力/油门后重新竖直标定。
若提示无有效响应，检查接收频率、推力、箭体是否被固定。不要通过取消保护来跳过标定。
若标定结果过期（更换引擎推力设置、接线、重心或结构），重新运行 `K`；标定不跨程序重启保存。

### 控制范围与限制

- 从连续两次姿态计算本体坐标角速度，兼容 CC: Sable 的 `{v, a}` 四元数与原始 `{x,y,z,w}` 格式，不依赖后端角速度的坐标约定。
- 每次采样后等待0.1秒，实际频率受接口调度影响，以 `Sample dt` 为准；两轴PD控制，输出限制为每个方向最多3档，无积分累积。
- 标定测得两路信号对两轴角加速度的响应矩阵，可识别交换轴和反接；弱响应、重叠轴、正反不一致会拒绝启用。
- 油门在标定值的0.5～2倍内做近似比例补偿；离开该范围会退出扶正、喷口回中，但保留你设定的手动油门。零油门不能扶正。
- 标定不是精确系统辨识：气动、喷口延迟、红石延迟和引擎非线性会影响结果。强响应、严重摆动时停止试验并调整推力配置。
- 3档限幅、16级红石精度可能产生小角度残差；不保证悬停或精准对接。
- 检测到传感器错误、结构变化、质量变化超过5%、扶正时采样间隔超过0.35秒、倾角超过25度或角速度超过1.5rad/s，会解除控制并清零。**这是试验停机策略，空中触发会下坠，不是自动救援。**
- 顶面不使用；五台引擎仍然同步，无法独立控制绕箭体长轴的自转，无法主动保持位置。
- 关闭电脑界面不会停机；区块卸载或强制中断不能由软件保证无线接收端清零。

已进行 Lua 5.2 数学、状态机、异常清零及简化自由刚体闭环测试；尚未在你的 Minecraft 世界实飞验证。

## 接线

方位均为 CC 电脑自身的相对面；front 是屏幕面，不是世界北方。

| CC 输出面 | 无线频率 | 接收端 |
| --- | --- | --- |
| front | 独立频率 F | 5台引擎同一偏转方向 |
| back | 独立频率 B | 5台引擎与 F 相反的偏转方向 |
| left | 独立频率 L | 5台引擎另一轴的一个方向 |
| right | 独立频率 R | 5台引擎与 L 相反的方向 |
| bottom | 独立频率 T | 5台引擎的推力红石输入 |

电脑旁的无线红石链路设为发送端。F/B/L/R 对应推进器自带的方向无线接收频率；T 的接收链路输出红石到每台推进器。
五种频率必须互不相同，且不能与其他机器串频。所有引擎安装朝向应一致；否则要调整各引擎接收频率，使其实际偏转同步。
保持信号路径独立，不要用会把强度放大为15的中继器；先确认接收端可分别收到1、2等模拟信号。
本程序不连接推进器外设，不要同时让另一台电脑通过外设接管这些推进器。
top 面不使用，也不会被程序改写。

## 使用

将单文件 engine.lua 放入 CC 文件系统，运行 `engine`。仓库发布后，在 CC 命令行逐行输入：

```text
wget https://raw.githubusercontent.com/ch126/cc-rocket-control/main/engine.lua engine.lua
engine
```

更新时先退出控制程序，再下载为 `engine-new.lua`，确认下载成功后备份旧文件并更名。
无需安装到 startup.lua，避免开机自动进入控制界面。CC 的 HTTP 下载功能需要开启。

| 按键 | 功能 |
| --- | --- |
| E | 启用控制／解除控制，切换时油门和方向清零 |
| R / F | 油门增加／减少1档，范围0～15 |
| W / S | front/back 轴偏转增加／减少1档 |
| D / A | right/left 轴偏转增加／减少1档 |
| C | 喷口回中，保持当前油门 |
| 空格 | 立即清零输出并解除控制 |
| Q 或 Ctrl+T | 清零输出并退出 |

按键为逐次点击调节，忽略键盘长按重复；松开键后设定保持。方向值范围为-15～15，是信号档位，不是角度。
正负值对应电脑输出面，不保证对应箭体运动方向。先固定箭体、零推力检查喷口朝向，再从1档油门测试。
五台引擎各自的创造推力设置仍需在游戏内配置；15档代表请求各自的满档输出，不是固定牛顿数。

## 限制

- 五引擎共用控制，无独立差动推力，也无独立滚转控制。
- 无姿态反馈、定高、自动着陆和塔架控制；关闭电脑界面不会停止程序或油门。
- 程序正常退出、Ctrl+T或可捕获错误时会尝试清零五个输出；进程强制中断、区块卸载、无线信号丢失等情况不能由 Lua 保证接收端归零。
- 清零指电脑输出，真实推进器和无线传输可能存在响应延迟。
- 无需额外安装模组；当前目标环境 CC: Tweaked 1.120.2、Create Propulsion 1.1.5。

接口依据：https://tweaked.cc/module/redstone.html
